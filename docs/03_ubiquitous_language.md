## 👤 アカウント関連

| 用語                  | 定義                                                           |
| --------------------- | -------------------------------------------------------------- |
| Guest（ゲスト）       | 未ログインのユーザー。認証（ログイン・新規登録）のみ実行できる |
| Account（アカウント） | ログイン済みのユーザー。すべてのデータ操作を行う主体           |
| Auth（認証）          | OAuth を用いたログイン／ログアウト機能                         |

---

## 🧊 食材（FoodItem）関連

| 用語                        | 定義                                                              |
| --------------------------- | ----------------------------------------------------------------- |
| FoodItem（食材）            | 冷蔵庫内で管理する対象1件。名前・期限・価格・保存場所・状態を持つ |
| FoodItemId（食材ID）        | 食材を一意に識別するID                                            |
| FoodName（食材名）          | 食材の名称。必須入力                                              |
| FoodImage（食材画像）       | 食材に紐づく画像（任意）                                          |
| BestBeforeDate（賞味期限）  | 食材の期限日付（任意）                                            |
| PurchasedAt（購入日）       | 食材を購入した日付（任意）                                        |
| Memo（メモ）                | 食材に関する補足情報（任意）                                      |
| Store（購入スーパー）       | 食材を購入したスーパー（任意）                                    |
| StorageLocation（保存場所） | 食材の保管場所                                                    |

---

## ✅ 食材状態（FoodStatus）関連

| 用語                     | 定義                       |
| ------------------------ | -------------------------- |
| FoodStatus（食材状態）   | 食材の現在の扱いを表す状態 |
| NotUsed（未消費）        | まだ使用していない状態     |
| InUse（消費中）          | 使いかけの状態             |
| Consumed（消費）         | 使い切った状態             |
| Discarded（廃棄）        | 捨てた状態（期限切れ等）   |
| StatusChange（状態変更） | FoodStatus を変更する操作  |

---

## 🏪 スーパー（Store）関連

| 用語                      | 定義                                   |
| ------------------------- | -------------------------------------- |
| Store（スーパー）         | 食材の購入先として記録する店舗         |
| StoreId（スーパーID）     | スーパーを一意に識別するID             |
| StoreName（店名）         | スーパー名。自由入力（統一ルールなし） |
| StoreList（スーパー一覧） | 登録済みスーパーを一覧表示する画面     |

---

## 📦 保存場所（StorageLocation）関連

| 用語                                      | 定義                                         |
| ----------------------------------------- | -------------------------------------------- |
| StorageLocation（保存場所）               | 食材の保管場所を表す区分                     |
| StorageLocationId（保存場所ID）           | 保存場所を一意に識別するID                   |
| LocationName（保存場所名）                | 保存場所の名称                               |
| DefaultLocation（固定保存場所）           | 初期から存在する保存場所（冷蔵／冷凍／常温） |
| CustomLocation（追加保存場所）            | ユーザーが追加した保存場所                   |
| DefaultLocationConstraint（固定場所制約） | DefaultLocation は削除できない               |

---

## 💰 価格記録（Price）関連

| 用語                              | 定義                                                |
| --------------------------------- | --------------------------------------------------- |
| PurchasePrice（購入価格）         | 食材に紐づく価格情報                                |
| OnePricePerFoodItem（1食材1価格） | 1つの食材に対して価格は1件のみ記録できる（MVP制約） |
| PriceView（価格表示）             | 店名＋価格を確認できる表示                          |

## 🔍 検索・表示関連

| 用語                   | 定義                                                           |
| ---------------------- | -------------------------------------------------------------- |
| FoodList（食材一覧）   | 食材を一覧表示する画面                                         |
| FoodDetail（食材詳細） | 食材1件の詳細を表示する画面                                    |
| Search（検索）         | 食材名の部分一致検索                                           |
| Sort（並び替え）       | 一覧を「賞味期限が近い順」「購入日が新しい順」に並び替える機能 |
